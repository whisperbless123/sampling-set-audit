## 0 研究问题与主张层级

**RQ1（主）**：在图族、信号族、结构/模型漂移三条轴上，学习式与黑箱优化式采样集选择方法，相对经典模型驱动方法（谱贪心一族）的成立边界在哪里？

**RQ2（次）**：评估预算严格对齐时，序贯学习（DQN 系）相对简单黑箱搜索（CEM）是否带来额外增益？——即"聪明试错"是否胜过"同价笨搜索"。已发表的 RL 采样工作（MAB/DQN）仅作为该设定的**来源与动机**引入，不是被检验对象。

**措辞红线（写作期与判读期同时生效）**：

| 允许 | 禁止 |
|---|---|
| "controlled characterization of regimes where …" | "we propose a novel sampler"（本文不提出方法） |
| "under a matched evaluation budget of E, …" | "CEM beats RL"（除非满足 §4 判优口径） |
| "method M did not reach the performance of X under budget E"（附预算与数字） | "RL is ineffective" 及任何委婉替代（如把训练失败写成 "sensitive to distribution shift"） |
| 引用先行 RL 采样工作作为研究对象与动机 | 声称先行工作错误或不诚实 |
| 论文身份 = 问题研究（预算换稳健性的成立边界） | 把论文框成"对已发表 RL 采样器的检验/批评"（稻草人框架） |
| 报告"在被测设置下"的发现 | 任何 "first / novel / 首次"类优先权主张（本文卖刻画，不卖优先权） |
| 刻画既有方法族的经验行为 | "we solve / address sampling under uncertainty"类求解式措辞（会引来 robust OED 基线要求） |

单 seed/单图结果不作显著性表述。"明显优于"的唯一口径见 §4。

## 1 任务定义（本协议最重要的冻结项）

**问题**：非自适应采样集选择。给定**选点期信息** `I_sel = (G_sel, M_sel, k)`——旧图、信号模型假设、预算——输出 `S ⊂ V, |S| = k`。之后进入**评估期**：真实信号 `x` 在 `G_eval` 上按 `M_eval` 生成，观测 `y = x_S + n`，重构 `x̂`，度量 NMSE。

三条冻结的边界：

1. **选点过程不得观测任何真实信号值。**逐节点顺序构造采样集（sequential construction）允许——这与已发表 DQN 采样设定一致；边采边看信号值的 signal-adaptive 采样**不在本文范围**，列为 future work，一句话带过。
2. **全部方法逐实例运行、共用同一份 `I_sel`，端到端 stale**：选点与重构都只用 `G_sel` 与 `M_sel`；漂移只体现在评估期的 `G_eval / M_eval`。不做跨图族摊销训练。
3. **oracle 参考线**：谱贪心在 `G_eval` 上重算 + 用 `L_eval` 重构，作为"无漂移上参考"画进图里，**不作为竞争方法**、不进胜负统计。

**统一重构器（全方法共用，重构器差异不进入比较）**：Laplacian 正则最小二乘
`x̂ = argmin_z ‖z_S − y‖² + μ·zᵀL_sel z`（闭式线性解）。
（贝叶斯注记：该重构器等价于 GMRF 先验 + 高斯噪声下的 MAP 估计；此解释仅供写作层使用，见 §6，引文入 §8。）
μ 的选定程序：主实验开始前，在每个（图族 × 信号族）组合的 **3 张校准图**（与评估图池不相交）上对 μ ∈ {1e-3, 1e-2, 1e-1, 1} 网格取最优，随后冻结；校准图不进任何结果表。

**规模**：主规模 N = 100；N = 300 仅作规模稳健性检验（§2 Block D）。采样率 k/N ∈ {5%, 10%, 20%}（仅 Block A 全扫，其余 Block 固定 10%）。

**指标**：NMSE = ‖x̂ − x‖²/‖x‖²（每图 200 条测试信号取均值）；管线评估次数（§3 记账口径）；墙钟时间（辅报）。

## 2 三轴设计与 cell 预算

**Axis-G 图族**（`G_sel` 的生成分布）：
- G1 = Erdős–Rényi(N, p)，p 取平均度 ≈ 8
- G2 = SBM(N, C=4 社区, p_in/p_out 取平均度 ≈ 8、社区内外比 8:1)
- G3 = Watts–Strogatz(N, 环邻居 8, β=0.1)

**Axis-S 信号族**（精确定义，S1/S2 必须可区分）：
- S1 精确带限 + 噪声：x = U_{:,1:r}·c，c ~ N(0, I)，r = ⌈0.1N⌉，观测噪声 SNR = 20 dB
- S2 扩散/GMRF 平滑（全带低通）：x ~ N(0, (L + εI)⁻¹)，ε = 1e-2，同 SNR
- S3 平滑底 + 局部异常：S2 信号叠加空间聚簇尖峰（支撑 = 5% 节点、取单个社区/邻域内，幅值 = 底信号 SD × 5）

**Axis-D 漂移**（选点期 → 评估期）：
- D0 无漂移：G_eval = G_sel，M_eval = M_sel
- D-G 结构漂移：度序保持随机重连，比例 ρ ∈ {5%, 15%, 30%}；信号在 G_eval 上生成，重构仍用 L_sel（端到端 stale）
- D-S 模型误设：(M_sel = S1, 实际 = S3) 与 (M_sel = S2, 实际 = S3) 两组，ρ = 0

**Cell 清单（冻结；裁剪顺序见括号）**：

| Block | 内容 | cell 数 |
|---|---|---|
| A | D0 主表：3G × 3S × 3 个 k | 27 |
| B | 结构漂移：3G × 3S × 3ρ，k=10%（时间不够先砍 ρ=5%） | 27 |
| C | 模型误设：2 组 × 3G，k=10% | 6 |
| D | 规模检验：N=300，(G_i, S_i) 对角 3 cell，D0，k=10% | 3 |
| E | 预算曲线：3 个代表 cell × E ∈ {500, 2000, 8000}，仅 CEM/DQN | — |
| F | 真实图 sanity：PyGSP 自带真实图 1 张（如 Minnesota），S2，D0；正文一句话，不进主表 | 1 |

预算粗估：每 cell ≈ 10 图 ×（2 个学习法 × 3 seed × 约 2 min + 廉价基线），单 cell ≈ 2–3 机时；A+B+C ≈ 150 机时，三台机器并行两天内可完成。**D1 结束时用实测单次评估耗时重估此表，超原估 1.5 倍即报出并按裁剪顺序砍。**

## 3 方法清单与公平性条款

**评估记账口径（冻结）**：一次"管线评估" = 对一个候选集 S，用 `M_sel` 在 `G_sel` 上模拟一批 32 条信号 → 重构 → 得平均 NMSE 的一次完整调用。计数器强制走统一 `eval.py` 模块，方法代码无权自行调用重构器。

| 方法 | 类型 | 评估预算 | 备注 |
|---|---|---|---|
| B1 Random | 基线 | 0 | 每 seed 独立抽取 |
| B2 Degree-greedy | 启发式 | 0 | 确定性 |
| B3a E-optimal 贪心 | 模型驱动强基线（对信号模型匹配） | 0 | 精确特征分解后贪心最大化 σ_min(U_{S,1:r})——Chen 2015 一系判据的精确版 |
| B3b λ_min 贪心 | 模型驱动强基线（对重构器匹配） | 0 | 贪心最大化 λ_min(diag(1_S) + μL_sel)——GDA 一系所逼近判据的精确版；N=300 用稀疏最小特征值求解 |
| B3c A-optimal 贪心 | 模型驱动强基线（对指标匹配） | 0 | 贪心最小化 tr((diag(1_S)/σ² + μL_sel)⁻¹)——S2 先验下平均 NMSE 的贝叶斯最优解析设计；Sherman–Morrison 增量更新 |
| M1 CEM | 黑箱优化 | **E = 2000** | population 50 × elite 10 × 40 代；直接优化模拟 NMSE |
| M2 DQN | RL（对齐先行设定） | **E = 2000** | 顺序构造：状态 = 已选集特征，动作 = 下一节点，终态 reward = −模拟 NMSE |

**论文防御句（冻结进正文）**：本文规模下（N ≤ 300）直接实现可扩展方法（谱代理、免特征分解定位算子、GDA、AVM）所逼近的最优设计判据的**精确版本**，比较反映这些判据的最强形态；相关工作中引用上述方法并以此句划界。三判据分别为 E 型 / λ_min 型 / A 型；漂移图中三者可并作"模型驱动族"细线以控图表密度。

**DQN 冻结超参**：MLP 2×128；节点特征 = [度, 聚类系数, 已选邻居计数, L 前 8 个特征向量分量]；lr 1e-3、replay 1e4、target 每 200 步、ε 从 1.0 线性降至 0.05（前 60% episodes）、γ = 1（有限步）。**超参不调优是设计决定**：预算对齐的比较中，调参预算同样须记账；本文使用默认超参并在 limitation 中声明。CEM 超参同理冻结。

（可选 B4：Sakiyama 定位算子 / GDA / AVM 的快速近似版——仅当想额外报告"近似 vs 精确判据"的差距时加入，非必需。）

## 4 种子、统计与判优口径

- 每 cell：**10 张独立图**；随机性方法（B1/M1/M2）每图 **3 个方法 seed**；确定性方法每图 1 次。每图 200 条测试信号。
- 汇总单位 = 图：每图先对 seed 与信号取均值，再报跨图均值 ± SD。
- **两层判定口径**：①**措辞层**——"明显优于"仅当同图配对差的 |均值| > 3 ×（两方法各自跨图 SD 之和）（沿用项目纪律）；达不到写"未见明显差异"或报区间。②**模式层（供 K4 检测用）**——一个 cell 内"序关系一致"定义为配对方向 ≥ 8/10 图同号；模式层只判方向存在，不授权任何强度措辞。配对 Wilcoxon p 值作参考性辅报，不作主判据。
- 全程留痕：每 run 记 config hash、全部 seed、git commit；结果落 JSONL；目录级 `PROVENANCE.md`。

## 5 判读与 kill 规则（先于数据冻结）

- **K1（D1 晚，管线自检）**：① S1 无噪、k = r、采样集使 U_{S,1:r} 列满秩且 cond(U_{S,1:r}) ≤ 1e6（随机重抽即可取得）条件下，用**带限 LS 自检重构器** x̂ = U_{:,1:r}(U_{S,1:r})⁺y 的 NMSE < 1e-8（容差见 §7）。该重构器与 R1 所用为同一个；协议全文重构器共两个——§1 统一主重构器（一切对比结果）与带限 LS（仅本条自检与 R1）。统一主重构器在无噪下无精确恢复为其固有性质，不作自检对象；② (G2, S1, D0, k=10%) 上 B3a NMSE ≤ Random，10/10 图成立；③ eval 计数审计：CEM/DQN 报告的评估次数恰等于协议预算。任一不过 → 停机排查，禁止调参硬闯。
- **K2（D3，RQ2 存续判据）**：D0 的 9 个 (G,S) cell（k=10%）中，CEM 相对 Random 在 ≥ 2 个 cell 达到 §4 措辞层口径改善，且不劣于 Degree。不过 → RQ2 降级为附带观察，主线转纯刻画（RQ1）；**触发降级时论文须如实披露 RQ2 未获支持，不得静默移除**。
- **K3（D5，RL 措辞闸门）**：DQN 无论结果如何照实报数 + 预算披露。若在 ≥ 5/9 个 D0 cell 未达 Random 水平，结论措辞限定为 "did not reach … under budget E = 2000"，并在 Block E 检查 E = 8000 是否翻转（翻转则报样本效率差距，不报能力缺失）。
- **K4（D6，可投判据）**：存在至少一条跨 cell 稳定模式——同一对方法的序关系在 ≥ 6/9 个 D0 cell **或** ≥ 6/9 个漂移 cell 上按 §4 **模式层**口径一致。不满足 → **不投**（出口就是不投，不转 OJSP）。
- **K4-b（regime 发现的资格线，先于数据冻结）**：一条稳定模式要升格为"regime 发现"（可进摘要与结论），须额外满足**轴条件谓词化**——存在某轴变量的明确划分（如 M_eval ≠ M_sel、ρ ≥ 15%、E ≥ 2000），使该模式在划分两侧呈现出现/消失或翻转；不可谓词化的孤立胜负只作 observation 报告。这同时是"成立边界"的失败条件定义：若无任何模式可谓词化，即宣告本设置下未找到边界结构。
- **R1（D6，非 kill，余力档）**：S1 各 cell 改用带限最小二乘重构器（投影到 U_{:,1:r} 的 LS）复验主序关系。序关系不变 → limitation 一句话带过；翻转 → 文中披露，并把涉及 S1 的结论限定为"拉普拉斯正则重构下"。目的：预先拆掉"统一重构器偏向某方"的审稿质疑。
- **两版并列纪律**：任何判据在见数据后出现定义争议，字面判定与修正判定并列报出，不改历史落档。

## 10 跨机执行纪律（是否启用由 D1 实测决定）

本研究的并行单元是 (cell, 图, 方法, seed)：run 之间零通信、无状态、单条分钟级——与长时有状态 RL 训练不同，**天然适合跨机，但也可能单机即够**。判据：D1_REPORT 实测耗时若显示 Block A+B+C 单机 ≤ 24 机时，则不启用跨机。启用时按以下六条执行：

1. **单一代码源**：所有机器 checkout 同一 git commit；依赖按同一 lock 文件安装；每条 run 记录 git HEAD 与 hostname。
2. **放行自检**：每台参与机器先复现同一条基准 run（cell = G2/S1/D0/k=10%，图 seed 0、方法 seed 0），NMSE 与主机之差须在 §7 容差内，否则该机不入池。
3. **数值确定性**：每 run 固定 BLAS/OMP 线程数为 1；并发靠进程数，不靠线程数。
4. **静态任务清单**：cell → 机器 的分配预先写死成清单文件；每条 run 完成落 DONE 标记；汇总机只按清单盘点缺漏，不做动态调度、不做抢占。
5. **结果搬运**：各机只写本机 runs/ 子目录；搬运到汇总机附 SHA256 清单逐一校验后方可入汇总。
