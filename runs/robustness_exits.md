# 两项稳健性的预注册出口

> 本文件于任何相关计算之前提交。出口一经入库，计算结果无论落在哪一侧，均按本文件执行。

## 一、门槛敏感性

- **范围**：K4-b 的七对合格模式，逐 cell 逐对以既有 `mean_d` 与两侧 SD 重算。
- **门槛集合**：3σ（基线）、4σ、5σ。**只向严处扫；不做 2σ**（放宽尺子只会新增"合格"，触既定发现配额）。
- **判据**：七对在各门槛下的存活集合。
- **出口 A**：七对在 3σ、4σ、5σ 下**全部存活** → 正文一句「边界对判据尺度在所扫范围内不敏感」。
- **出口 B**：任一门槛下**存在不存活** → **照实报出各门槛的存活集合与存活区间**；resolvability 的辖域**绑定 3σ**。
- **不变量**：3σ 仍为唯一主张门槛（保持不变）；本项不改任何既有判读落点。

## 二、μ 敏感性

- **形态**：复用**冻结采样集**，**不重新选点、不重新训练**，只在 μ/10 与 10μ 下重评，做**模式层**序检。与 R1同型。
- **范围**：依预先记录的范围；原文未载则九个 D0 cell 全做。
- **口径**：模式层（配对方向 ≥ 8/10 同号）。**不做措辞层，不新造 δ。**
- **出口 A**：模式层序在 μ/10 与 10μ 下**保持** → 正文一句「核心边界在 μ 一个数量级内不敏感」入 §4。
- **出口 B**：序**有变** → **照实报出**；C2 的辖域**绑定冻结的重构规格**；既有的 limitation 句保留。
- **时限**：结果须在 全稿排版前落档；**未及则本项作废**，既有 limitation 句维持，**不得在排版后补入**。
